## 4. إقرار الخصوصية (App Privacy Label)

### أ. تطبيق العميل (`com.shipping.clientapp`):
1. **Contact Info (بيانات الاتصال):**
   - الاسم (Name) + رقم الجوال (Phone) + البريد (Email): لربط الحساب والمصادقة بالـ OTP والتواصل لتسليم الشحنة.
2. **User Content (محتوى المستخدم):**
   - الصور (Photos): التقاط وإرفاق حتى 5 صور للطرود لتوثيق حالة الشحنة.
3. **Location (الموقع الجغرافي):**
   - تحديد المدينة والمنطقة لتوجيه طلب الشحن للكباتن المتواجدين فيها.
4. **Identifiers (المعرفات):**
   - Session Tokens مخزنة في iOS Keychain للمصادقة الدائمة.
5. **Data Used to Track You (التتبع عبر أطراف ثالثة):**
   - **لا يوجد أي تتبع للمستخدمين (NO Tracking).**

### ب. تطبيق السائق (`com.shipping.driverapp`):
1. **Contact Info:** الاسم + رقم الجوال + البريد + رقم لوحة المركبة.
2. **Location (الموقع الجغرافي أثناء الاستخدام):** لتوجيه مسار التوصيل للعميل وتحديث حالة الطلب أثناء القيادة.
3. **Identifiers:** Session Tokens في Keychain.
4. **Data Used to Track You:** **لا يوجد تتبع (NO Tracking).**
