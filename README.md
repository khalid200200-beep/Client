# 📦 تطبيق فلاتر للشحن والتوصيل (Flutter Shipping App)

تطبيق متكامل وسلس لإدارة عمليات الشحن والتوصيل تم تصميمه وبرمجته وفق أحدث معايير Flutter مع واجهة مستخدم (UI/UX) مطابقة للتصميم وموجهة للمستخدم العربي (RTL كامل).

---

## 🌟 الميزات المنفذة في التطبيق

1. **الواجهة الرئيسية المتطابقة (Home Screen):**
   - رأس الصفحة مع ترحيب العميل، المدينة (الرياض 📍) وزر الإشعارات.
   - البانر الترويجي الكبير مع تأثير ثلاثي الأبعاد والزر الأحمر المتوهج (`اطلب شحن الآن`).
   - بطاقات الإجراءات السريعة: **طلباتي**، **تتبع الشحنة**، **الدعم**.
   - بطاقة الترويج السفلية (`⚡ سريع وآمن - مندوبنا يصل إليك`).
   - شريط التنقل السفلي مع الزر العائم المركزي الأحمر (`+ شحن جديد`).

2. **إنشاء حساب والتحقق (Auth & OTP):**
   - إدخال الاسم، رقم الجوال، اختيار المدينة، كلمة المرور، ورمز تحقق SMS تجريبي.

3. **شاشة طلب الشحن (Create Order):**
   - رقم هاتف العميل.
   - عداد لاختيار عدد القطع / الطرود (`+ / -`).
   - تصوير الشحنة بالكاميرا أو اختيار صورة.
   - حقل الملاحظات وتحديد المدينة وتأكيد الإرسال.

4. **شاشة السائق والمندوب (Driver Flow):**
   - استقبال الطلبات في نفس المدينة فورياً.
   - قبول الطلب (`✅ قبول`) أو رفضه (`❌ رفض`).
   - عند الوصول للعميل: زر `تم التحميل` بنجاح أو زر `تعذر الشحن` مع تحديد السبب.

5. **لوحة التحكم والإحصائيات (Admin Dashboard):**
   - إحصائيات حية لعدد الطلبات، الطلبات المحملة، المعلقة، والمتعذرة.

6. **مبدل الأدوار السريع (Role Switcher):**
   - من خلال القائمة العلوية في الشاشة الرئيسية، يمكنك التبديل الفوري بين **منظور العميل**، **شاشة السائق**، و **لوحة الإدارة**.

---

## 🚀 طريقة التشغيل (How to Run)

1. افتح موجه الأوامر (Terminal) في مجلد المشروع:
   ```bash
   flutter pub get
   ```

2. لتشغيل التطبيق على الهاتف (iOS / Android) أو المتصفح (Chrome):
   ```bash
   flutter run
   ```
